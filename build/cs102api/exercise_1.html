Exercise: Guess the Number!¶

In this exercise, you will play a game with an API: the API has a secret number, and you will try to guess it. The API will tell you if your guess is too high or too low. The number is between 1 and 50.

The endpoint for the API is: https://one02-api-fastapi.onrender.com/api/guess

This endpoint will process your guess, so you will need to POST a request to it. Your guess should be in the body of the request, and it should look like this:

{ "guess": 25 }

Now, write the code for these plans by copy pasting the code from the plans! Let’s see if you can guess the number!

Here is a list of all programming plans you have learned today:

Set Target URL: Enter the URL for the API you will use.
import requests
target_url = 'url'
url The URL of the API you want to query.
Set Parameters: Enter parameters that will affect the response from the API.
my_params = {
    key_value_pair,
}
key_value_pair A "key" that refers to the type of information, and a "value" that is the information you need to send to the API. You can add multiple pairs to send more information, depending on the API.
Set Authentication Credentials: If the API requires a log in or a similar authentication, share your credentials
headers = {
        'Authorization': authorization_token
}
authorization_token TODO
Set Private Content: If you are calling an API on your data, send the data in the body of your message.
body = {
    'message': 'Hello! How are you ChatGPT?'
    }
Make GET Request: Call the API by making a GET request to the server.
response = requests.get(target_url, params=params)
params You can either send your parameters, or call the API with no parameters.
Make POST Request: Call the API with private data by making a POST request to the server.
response = requests.post(target_url, headers=headers, json=body)
headers Headers you may want to set, such as the authorization information.
body The body of your request, which will include the sensitive information you want to share with the server.
Show Result If Successful: Check if response was successful, and show the data or the error message depending on the result.
# Check the result of the request
if response.status_code == status_code:
    process_result
status_code A number that represents whether the request was successful (200) or had some particular error.
process_result This line processes the response to generate a result: It may show the response from the server or it might show an error message.
